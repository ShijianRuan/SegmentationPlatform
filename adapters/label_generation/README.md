# 标签生成适配器

> 状态：共同边界已确定，具体算法按需接入

本目录用于接入能够自动产生候选标签的模型或算法，例如：

- 当前已有模型的离线批量推理；
- TotalSegmentator 等外部工具；
- 经过验证的研究模型。

每个具体工具都可以有不同输入和运行环境，但输出必须统一。

## 统一输出

一次批量运行至少产生：

- 输入图像标识；
- 生成器名称、版本和参数；
- 使用的模型或外部工具版本；
- 外部器官名到平台统一器官名的映射；
- 每个输出文件及其哈希；
- 空间信息和质量检查结果；
- 逐病例成功或失败状态；
- 可用于避免重复运行的唯一键。

成功结果登记为候选标签（`candidate_label`），不会自动变成已验证标签。

## 后续去向

候选标签可以：

- 进入标注域，作为人工修正的初始 Mask；
- 保持候选状态，在创建训练数据快照时由明确策略判断是否准入；
- 因检查失败而被拒绝。

## 本目录不决定

- 人工如何修正和提交；
- 训练任务中的整数标签编号；
- 数据许可是否满足某个业务用途；
- 模型的正式测试标准；
- 某个候选标签是否允许进入具体训练。

具体算法只有在真正开始实现时才建立自己的子目录。不要提前为未选定的方法创建空适配器。
