# nnUNet 适配器

> 状态：边界已确定，平台导出逻辑尚未独立实现

本适配器负责把平台创建的训练数据快照转换成 nnUNet 能读取的数据集。

当前训练代码仍在 [`pipelines/nnunet/`](../../pipelines/nnunet/)。这里不会复制或重写训练核心。

## 需要实现

1. 读取一个不可变的训练数据快照。
2. 使用任务标签映射，把统一器官名转换为从 1 开始的连续整数。
3. 按快照中已经冻结的训练、验证和测试划分导出病例。
4. 检查标签覆盖、缺失标签、空类别和患者泄漏。
5. 生成真实的 `dataset.json` 和运行配置。
6. 训练结束后登记模型；独立测试完成后登记评估结果。

## 当前训练管线的已知限制

- 没有外部病例表时，现有随机划分不能保证固定种子和患者级隔离；
- 缺少某个器官 Mask 时，现有转换可能把它保留为背景；
- `dataset.json` 的来源和许可字段存在硬编码；
- Surface Dice 依赖未启用，正式评估不能直接照搬现有结果。

适配器必须在启动训练前处理这些问题，不能要求 nnUNet 在运行中猜测平台规则。

详细现状见 [nnUNet 训练管线参考](../../docs/domains/training/nnunet_pipeline_reference.md)。
