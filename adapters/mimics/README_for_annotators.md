# Mimics 标注员说明

> 状态：第一阶段手动闭环说明；不是自动化插件文档。

当前阶段的目标不是把 Mimics 完全集成到平台，而是先稳定跑通：

`Case Package -> Mimics 打开 -> 人工修正 -> 导出 mask -> 平台校验`

当前最小要求：

1. 打开病例图像。
2. 导入草稿标签或逐器官 mask。
3. 完成人工修正。
4. 导出逐器官 mask 或可回收的标签结果。

平台侧之后会负责：

- 合并 mask
- 校验 geometry
- 注册为 `verified_label`

如果某个病例在 Mimics 中出现方向、spacing、mask 对不齐等问题，不要直接继续导出到训练，应先回到平台侧做问题记录和几何核查。
