# 工具适配器

适配器负责把平台数据转换成具体工具能够读取和输出的形式。

可以把它理解为“翻译层”：

- 平台使用病例、图像、标签和训练数据快照等统一记录；
- Mimics、nnUNet 或外部算法各有自己的目录、文件和参数；
- 适配器负责两者之间的转换，但不改变平台规则。

## 当前目录

| 目录 | 用途 | 当前状态 |
|---|---|---|
| `mimics/` | 保存 Mimics Python 3.5.2 脚本和探针；平台侧代码另在 `src/segplatform/adapters/mimics/` | [双运行时设计](../docs/domains/labeling/mimics_adapter_design.md)已明确，代码待实现 |
| `nnunet/` | 把训练数据快照导出成 nnUNet 数据集 | 已定义边界，训练核心仍在 `pipelines/nnunet/` |
| `label_generation/` | 接入能够生成候选标签的模型或算法 | 已定义共同输出要求 |

少样本学习不单独建立通用 `fewshot/` 目录。少样本描述的是数据选择和实验方式，不是一个具体工具：

- 少量病例训练 nnUNet，仍使用 nnUNet 适配器；
- UniverSeg 等方法只有真正开始复现时，才建立各自的具体适配器；
- 通过评估后用于批量生成标签的方法，再接入标签生成目录。

## 适配器必须遵守的边界

适配器可以负责：

- 文件和目录转换；
- 参数映射；
- 工具启动；
- 输出收集；
- 工具侧错误转换成平台可读报告。

适配器不能自行决定：

- 标签是否已验证；
- 标签是否允许进入训练；
- 患者如何划分训练、验证和测试集；
- 数据许可是否满足具体用途；
- 平台记录是否可以被覆盖。

这些规则由平台数据记录和训练数据快照决定。术语说明见 [文档术语表](../docs/glossary.md)。
