# CADS 器官分割中的伪标签技术详解

> **CADS** (Comprehensive Anatomical Dataset and Segmentation) — 22,022 例 CT、167 个解剖结构的全身 CT 分割框架
>
> 论文: [arXiv:2507.22953](https://arxiv.org/abs/2507.22953) | 数据集: [Hugging Face](https://huggingface.co/datasets/mrmrx/CADS-dataset) | 代码: [GitHub](https://github.com/murong-xu/CADS)

---

## 一、背景：为什么需要伪标签

CADS 汇集了来自 40+ 数据源、100+ 影像中心、16 个国家的 22,022 例 CT 扫描。然而，其中**仅有约 21%（4,695 例）的扫描拥有部分手动或混合标注**。面对如此大规模的数据，完全依靠人工标注是不可能完成的任务——伪标签技术因此成为整个 CADS 项目的核心支柱。

> 核心命题：如何利用少量有标注数据 + 海量无标注数据，自动生成覆盖 167 个解剖结构的高质量分割标注？

---

## 二、伪标签流水线总览

CADS 的伪标签生成是一个**四阶段自动化流水线**，从少量真实标注出发，逐步向外扩展、精炼，最终覆盖全部 22,022 例 CT。

```
┌──────────────────────────────────────────────────────────────────┐
│                    CADS 伪标签生成流水线                           │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  阶段 1 · 初始区域模型训练                                         │
│  ┌─────────────────────────────────────────────────────────┐     │
│  │ 少量全标注数据 → 训练 9 个区域专用 nnU-Net                 │     │
│  │ → 在各区域生成全部 22,022 CT 的初始伪标签                  │     │
│  └─────────────────────────────────────────────────────────┘     │
│                              ↓                                    │
│  阶段 2 · 自动化形状质量控制                                       │
│  ┌─────────────────────────────────────────────────────────┐     │
│  │ 神经隐式函数 + 形状先验 → 计算每个伪标签的解剖合理性评分    │     │
│  │ → 排除评分最低的 10% 伪标签                                │     │
│  └─────────────────────────────────────────────────────────┘     │
│                              ↓                                    │
│  阶段 3 · 三味策略生成（Multi-Flavor）                              │
│  ┌─────────────────────────────────────────────────────────┐     │
│  │ GT-flavor    — 仅真实标注训练 → 高精度、低覆盖             │     │
│  │ Pseudo-flavor — 全部伪标签训练 → 广覆盖、含噪声             │     │
│  │ Shape-flavor  — 过滤后伪标签训练 → 质量与覆盖的平衡         │     │
│  │ → 统计检验选出每个结构的最优 flavor                         │     │
│  └─────────────────────────────────────────────────────────┘     │
│                              ↓                                    │
│  阶段 4 · 标签组装                                                 │
│  ┌─────────────────────────────────────────────────────────┐     │
│  │ GT 标注最高优先级 · 类别平衡过采样 · 任务特定子集优化        │     │
│  │ → 组装最终的 CADS-dataset                                  │     │
│  └─────────────────────────────────────────────────────────┘     │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

## 三、阶段 1：初始区域模型训练

### 3.1 区域划分策略

不同于训练一个统一模型覆盖全部 167 个结构，CADS 将解剖结构分为 **9 个区域组**，每组训练一个专用模型。这种**区域专业化**策略有三个关键优势：

1. **降低单模型复杂度**：每个模型只需掌握有限的结构类别
2. **优化计算资源**：可按需加载特定区域模型，无需一次性加载完整模型
3. **提升伪标签精度**：区域模型在各自领域内更精准

| 任务 ID | 结构数 | 覆盖内容示例 |
|---------|--------|-------------|
| 551 | 16 | 脾、肾、胆囊、肝、胃、主动脉、下腔静脉、门静脉、胰腺、肾上腺、肺叶 |
| 552 | 24 | 颈椎 C1–C7、胸椎 T1–T12、腰椎 L1–L5 |
| 553 | 25 | 食管、气管、心腔、肺动脉、脑、髂血管、小肠、十二指肠、结肠、膀胱 |
| 554 | 20 | 肱骨、肩胛骨、锁骨、股骨、髋骨、骶骨、臀肌、背深肌、髂腰肌 |
| 555 | 24 | 肋骨 1–12（左/右各 12 条） |
| 556 | 21 | 椎管、喉、心、乙状结肠、直肠、前列腺、精囊、乳腺、胸骨、腹直肌 |
| 557 | 18 | 白质、灰质、脑脊液、头皮、眼球、密质骨/松质骨、血液、头肌 |

| ANTS 配准 + SimNIBS 图谱 | — | 脑结构 | 脑区伪标签生成 |

## 四、阶段 2：形状引导的自动化质量控制

这是 CADS 伪标签流水线中**最具原创性的技术环节**。传统的伪标签质量控制通常依赖模型预测置信度（如 softmax 概率），但**高置信度并不等于解剖合理性**——一个模型可能对错误的预测也非常"自信"。

### 4.1 核心思想

CADS 引入了一个根本性的视角转换：

> **在形状空间中评估伪标签质量，而非在概率空间中。**

具体的，使用**神经隐式函数（Neural Implicit Functions）**学习真实标注的形状流形（shape manifold），然后将每个伪标签投影到这个流形上，计算投影距离作为质量度量。

### 4.2 技术实现

```
训练阶段：
  真实标注 (GT) → 训练 auto-decoder (基于隐式神经表示)
                  → 学习解剖结构的形状流形

推理阶段：
  伪标签 → auto-decoder 重建 → 重建后的"合理"形状
         → 计算原始伪标签与重建形状的 90 分位 Hausdorff 距离
         → 距离大 = 偏离形状流形 = 质量低
         → 排除评分最低的 10%
```

**为什么选择 90 分位 Hausdorff 距离？**
- Hausdorff 距离对异常值高度敏感，能有效检测局部解剖异常
- 使用 90 分位而非最大值，避免少数极端体素（如边界噪声）过度惩罚整个伪标签
- 在敏感性与鲁棒性之间取得了平衡

### 4.3 关键特性

| 特性 | 含义 |
|------|------|
| **全自动化** | 无需人工审查，可扩展到 22,000+ 级别数据 |
| **仅需 GT 训练** | 不需要构造"坏"分割样本，降低了训练数据需求 |
| **零样本异常检测** | 推理时无需见过低质量伪标签，直接在形状空间中判断 |
| **形状空间操作** | 比图像空间更低维、更本质，剔除了纹理、强度等干扰因素 |
| **10% 排除阈值** | 经验选择，排除明显异常但保留足够的训练数据 |

### 4.4 潜在局限

形状 QC 可能**系统性排除病理解剖变异**（如肿瘤占位导致器官变形、术后解剖改变等）。这是质量与包容性之间的权衡——在 22,022 例数据规模下，人工逐例审核病理变异是不现实的。

## 五、阶段 3：三味策略（Multi-Flavor Strategy）

### 5.1 设计哲学

CADS 的核心洞察是：**没有一种伪标签策略对所有解剖结构都是最优的。**

- 对于**小而复杂的结构**（如耳蜗、视交叉），伪标签的噪声代价太大，宁愿用少量高质量 GT 标注训练
- 对于**常见的大结构**（如肝脏、肺），需要尽可能多的数据来覆盖解剖变异
- 对于**形状特征明显的结构**（如椎骨、肋骨），形状先验可以有效滤除低质量伪标签

### 5.2 三种 Flavor 的设计

```
                    ┌──────────────────────────────────┐
                    │        数据质量 (Quality)          │
                    │        高 ←───────────→ 低         │
                    │                                  │
                    │   ┌─────────┐                    │
                    │   │GT-flavor│                    │
                    │   │ (纯GT)  │                    │
                    │   └────┬────┘                    │
                    │        │                         │
                    │   ┌────┴────┐                    │
                    │   │ Shape-  │                    │
                    │   │ flavor  │                    │
                    │   │ (前90%) │                    │
                    │   └────┬────┘                    │
                    │        │                         │
                    │   ┌────┴────┐                    │
                    │   │ Pseudo- │ ← 数据量 (Scale)    │
                    │   │ flavor  │   大                │
                    │   │ (全量)  │                    │
                    │   └─────────┘                    │
                    │                                  │
                    └──────────────────────────────────┘
```

| Flavor | 训练数据 | 样本量 | 标签质量 | 最佳适用场景 |
|--------|---------|--------|---------|-------------|
| **GT-flavor** | 仅原始真实标注 | 最小 (~4,695) | 最高 | 小/复杂结构（耳蜗、视交叉、杓状软骨） |
| **Pseudo-flavor** | 全部 22,022 伪标签 | 最大 (22,022) | 含噪声 | 常见大结构（肝、肺、肾、脾） |
| **Shape-flavor** | 经形状 QC 过滤的前 90% | 中等 (~19,820) | 过滤后较好 | 形状规律性强的结构（椎骨、肋骨、长骨） |

### 5.3 统计选择算法

对于每个解剖结构，最终使用哪个 flavor 的伪标签，不是靠直觉或经验判断，而是通过**严格的统计检验流程**决定：

```
Algorithm 1: 逐结构 Flavor 选择

输入: 167 个解剖结构，3 种 flavor 模型
输出: 每个结构的最优 flavor 分配

对于每个解剖结构：
┌─────────────────────────────────────────────────────┐
│ Step 1: 性能评估                                      │
│   - 优先使用 OOD (Out-of-Distribution) 验证集          │
│   - OOD 不可用时回退到 ID (In-Distribution) 验证集     │
│   - 计算每个 flavor 在各验证样本上的 Dice 分数          │
├─────────────────────────────────────────────────────┤
│ Step 2: 正态性检验                                    │
│   - Shapiro-Wilk 检验: H₀ = 数据服从正态分布            │
│   - 同时检查方差齐性 (Levene 检验)                      │
├─────────────────────────────────────────────────────┤
│ Step 3: 组间差异检验                                   │
│   - 正态 + 方差齐 → 单因素 ANOVA                       │
│   - 正态 + 方差不齐 → Welch ANOVA                     │
│   - 非正态 → Kruskal-Wallis 秩和检验                   │
├─────────────────────────────────────────────────────┤
│ Step 4: 事后两两比较                                   │
│   - 参数检验后 → Tukey HSD                            │
│   - 非参数检验后 → Dunn 检验                           │
├─────────────────────────────────────────────────────┤
│ Step 5: 排名与选择                                     │
│   - 根据统计显著性差异或均值大小赋予排名                 │
│   - Dice 平局 → 使用 HD95 作为二次评估指标             │
│   - 排名最高的 flavor → 该结构的最终伪标签来源          │
├─────────────────────────────────────────────────────┤
│ Step 6: GT 覆盖                                      │
│   - 原始 GT 标注始终覆盖同位置的伪标签                  │
│   - 优先级: GT > 选中 flavor > 其他 flavor             │
└─────────────────────────────────────────────────────┘
```

**为什么优先使用 OOD 验证？**

OOD（分布外）数据来自与训练集不同的数据源/扫描协议，更能反映模型的真实泛化能力。在医学影像中，不同设备、协议、中心的数据分布差异显著——选择一个在 ID 上表现好但在 OOD 上崩溃的 flavor 是没有临床意义的。

## 六、阶段 4：标签组装与最终训练

### 6.1 标签优先级规则

```
GT 原始标注  >  统计选出的最优 Flavor 伪标签  >  其他 Flavor 伪标签
  (硬覆盖)          (主体标注)                    (不参与最终标注)
```

这意味着：对于有原始 GT 标注的结构，优先保留 GT；对于无 GT 的结构，使用最优 flavor 的伪标签填充。这种设计确保了标注质量的下限由 GT 保证，而上限由伪标签扩展。

### 6.2 处理类别不平衡

部分解剖结构在数据集中天然稀有：
- **C1–C5 椎骨**在大量胸部 CT 中不可见（扫描范围未覆盖到颈部）
- **耳蜗、视交叉**等微小结构体积极小

CADS 针对这些稀有结构采用了**类别平衡过采样**策略：在训练批次中增加包含稀有结构的样本比例，避免模型偏向常见结构。

### 6.3 任务特定子集优化

在训练 Pseudo-flavor 时，并非简单使用全部 22,022 例数据训练所有模型，而是使用**任务相关的子集**：

- 训练头部模型（任务 557, 558）时，仅使用包含头部的扫描
- 训练腹部模型（任务 551）时，仅使用包含腹部的扫描

这种过滤避免了模型在不相关数据上浪费计算，同时防止了"背景类"对伪标签质量的负面影响。

## 七、伪标签技术的分类定位

### 7.1 CADS 在半监督学习谱系中的位置

```
半监督学习 (Semi-Supervised Learning)
│
├── 伪标签 / 自训练 (Pseudo-Labeling / Self-Training) ← CADS 主体
│   ├── 硬伪标签 (Hard): argmax → 离散标签 ────────── CADS 使用
│   ├── 软伪标签 (Soft): 概率分布 → 知识蒸馏
│   ├── 置信度过滤: 仅保留 max_prob > τ ────────────── CADS 未用
│   └── 迭代自训练: 多轮伪标签 → 重训练 ──────────── CADS 部分使用
│
├── 一致性正则化 (Consistency Regularization)
│   ├── Mean Teacher: θ_teacher = EMA(θ_student)
│   ├── Π-Model / Temporal Ensembling
│   └── VAT (Virtual Adversarial Training)
│
├── 混合方法 (Hybrid)
│   ├── FixMatch: 弱增强 → 伪标签 + 强增强 → 一致性
│   ├── Cross-Pseudo Supervision (CPS): 双网络互监督
│   └── Noisy Student: 教师 → 伪标签 → 学生 + 噪声
│
└── CADS 独特创新 ─────────────────── 不属于以上任何单一类别
    ├── 区域专用化 (Region-Specific): 9 个区域独立生成
    ├── 多味集成 (Multi-Flavor): 3 种互补策略
    ├── 形状空间 QC: 神经隐式函数 + 形状先验
    └── 统计选择: 逐结构假设检验选择最优策略
```

### 7.2 与主流方法的对比

| 方法 | 标签生成方式 | 质量控制机制 | 数据利用效率 | 适合场景 |
|------|------------|-------------|-------------|---------|
| **FixMatch** | 单模型 + 弱增强 | 置信度阈值 τ (通常 0.95) | 丢弃低置信度样本 | 分类为主 |
| **Mean Teacher** | EMA 教师模型 | 教师模型稳定性 | 利用全部无标签数据 | 通用 SSL |
| **CPS** | 双网络互监督 | 架构多样性互相纠错 | 充分利用 | 中等规模器官分割 |
| **Noisy Student** | 教师→学生+噪声 | 学生模型鲁棒性 | 大规模数据 | 大规模通用分割 |
| **CADS** | 9 区域专用 + 3 flavor | **形状空间合理性 + 统计检验** | 分层利用（GT/Shape/All） | **万级大规模全身器官分割** |

### 7.3 CADS 伪标签策略的独特贡献

CADS 的伪标签策略有几个在以往方法中不常见的创新：

1. **形状先验替代置信度先验**：将质量评估从"模型有多确定"转变为"分割有多像真实解剖结构"，这在医学影像——特别是器官分割——中意义重大，因为解剖结构具有强烈的形状约束。

2. **策略多样性的系统利用**：不是试图找到"最好的"伪标签策略，而是为每个结构找到"最合适的"策略。这承认了不同解剖结构的数据特征本质上不同。

3. **统计严谨性的工程化**：将完整的统计检验流程嵌入自动化流水线，而非手动调参或视觉检查。这使方法可以在 167 个结构上自动化运行而不失严谨。

4. **质量-数量的显式建模**：GT-flavor（高质量/低数量）、Pseudo-flavor（低质量/高数量）、Shape-flavor（中等质量/中等数量）——三种 flavor 在质量-数量二维平面上形成了明确的帕累托前沿探索。

## 八、伪标签效果验证

### 8.1 最终数据集质量

| 评估维度 | 指标 |
|---------|------|
| 全部 167 结构平均 Dice | **85.87%** |
| 专家验证子集 Dice | **93.15%** |
| 与 TotalSegmentator 共有的 119 结构 | **90.52%** vs 88.09% (+2.43%) |
| 统计学显著提升结构数 | 44/119 |

### 8.2 伪标签策略的间接消融证据

虽然论文未对三种 flavor 进行严格的"拆除实验"，但以下结果间接证明了多策略方法的有效性：

- **复杂小器官的大幅提升**：脑干 (+23.7%)、视神经 (+9.8-15.3%) 等——这些结构受益于 GT-flavor 的高精度
- **常见大器官的稳定提升**：肝、肾、脾等在全部 18 个外部数据集上的一致改善——受益于 Pseudo-flavor 的广泛覆盖
- **骨骼结构的细节改善**：肋椎关节（costovertebral joint）的精确勾勒——受益于 Shape-flavor 的形状先验

### 8.3 临床验证

- **2,864 例**来自苏黎世大学医院的独立肿瘤患者队列
- 35 个解剖结构由**资深放疗科医师**（5.5 年经验）逐层审查
- 结论：伪标签组装的分割质量 **"达到放疗计划的临床标准"**

## 九、局限与未来方向

### 9.1 当前局限

| 局限 | 描述 | 影响 |
|------|------|------|
| 病理变异排除 | 形状 QC 可能过滤掉异常但真实的解剖 | 罕见病、术后改变可能被错误排除 |
| 极小结构 | <0.5 mL 的结构（如杓状软骨）受部分容积效应限制 | 分辨率瓶颈，非伪标签问题 |
| 覆盖范围 | 头到膝，不含手足 | 某些应用场景不适用 |
| 数据依赖 | 初始训练仍需要跨多个数据源的有标注数据 | 启动成本较高 |

### 9.2 未来方向

1. **基础模型 + 形状先验联合**：将 SAM、MedSAM 等基础模型的零样本分割能力与形状先验 QC 结合，可能进一步降低初始标注需求。

2. **病理感知的形状 QC**：在形状模型中引入病理状态的条件变量，允许对病理解剖变异建模而非简单排除。

3. **不确定性驱动的伪标签选择**：将形状空间的不确定性与概率空间的不确定性融合，形成更全面的质量评估。

4. **主动学习集成**：对形状 QC 评分处于边界（如 8-12 分位）的伪标签，通过主动学习选出最有价值的样本进行人工审核。
