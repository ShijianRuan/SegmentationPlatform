# 对话记录与问题处理

这个目录保存对设计有影响的重要对话记录，以及把问题落到当前结论、实现状态和后续任务的处理清单。

| 文件 | 用途 |
| --- | --- |
| [chat_conversation_cleaned.md](chat_conversation_cleaned.md) | 整理后的原始对话记录，保留问题提出和当时回复 |
| [chat_conversation_resolution.md](chat_conversation_resolution.md) | 当前项目对这些问题的重新分析、解释和处理结果 |

这里的文档不直接定义平台行为。若与现行架构、数据模型或域契约冲突，以 `docs/architecture/` 和 `docs/domains/` 下的当前文档为准。
