# 跨域研究材料

> 状态：研究层，不直接定义平台架构或生产能力。

## 1. 主文档

[医学图像少样本学习与少样本分割调研](few_shot_learning_survey.md)是当前唯一的综合调研主文档。

原先并行存在的另一份同名草稿包含大量未充分限定的性能数字、开源状态和工程建议，已删除；原 `_merged` 文档改为当前规范文件名。

[少样本实验如何接入平台](few_shot_platform_integration.md)说明如何复用训练数据快照、少样本实验清单、具体工具适配器和模型记录，不属于当前实施计划。

## 2. 资料层级

| 位置 | 用途 | 是否可直接作为事实 |

## 3. 使用规则

1. 研究候选只有在完成数据协议、复现实验、评估和风险检查后，才能升级为正式 Adapter。
2. 性能数字必须同时记录数据集、shot、split、指标和来源。
3. 开源状态、论文状态和仓库可用性可能变化，实施前需重新核查。
4. 与平台蓝图冲突时，以 `docs/architecture/platform_blueprint.md` 为准。
